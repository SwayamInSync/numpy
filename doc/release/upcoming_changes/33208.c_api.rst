Promoters for a requested output DType
--------------------------------------
A promoter registered with ``PyUFunc_AddPromoter`` whose input DTypes are all
``None`` or ``np.dtype`` and whose output DType is concrete, such as
``(np.dtype, np.dtype, MyDType)``, is now only used when that output DType is
requested with ``dtype=`` or ``signature=``. Such a promoter allows
``np.add(a, b, dtype=MyDType)`` for inputs of other DTypes. Previously it also
matched every call without a requested output and took over the promotion of
unrelated DTypes.
