New ``NPY_DT_REPACK_PYSCALARS`` DType flag
------------------------------------------
User DTypes can set the new ``NPY_DT_REPACK_PYSCALARS`` flag so that Python
``int``, ``float``, and ``complex`` operands of ufuncs, and Python scalars
passed to ``np.copyto``, ``np.full``, and ``np.ones``, are converted directly
to the descriptor the operation resolves, instead of to the DType's default
descriptor followed by a cast. This lets parametric DTypes accept Python
scalars when casts from their default descriptor are lossy or not allowed.
